# Machine à café automatique — TIA Portal

Projet d'automatisation d'une machine à café réalisé avec Siemens TIA Portal.

## Présentation

Ce dépôt contient le projet de la machine à café dans une archive compressée.
Il peut être extrait puis ouvert dans une version compatible de TIA Portal.

## Contenu du dépôt

| Fichier | Description |
| --- | --- |
| `Automatic Coffee Machine.rar` | Archive du projet d'automatisation |

## Prérequis

- Windows
- Siemens TIA Portal, dans une version compatible avec le projet
- Un outil capable d'extraire les fichiers `.rar`

> La version de TIA Portal et la référence de l'automate ne sont pas précisées dans ce dépôt. Vérifiez-les dans le projet extrait avant de le charger sur un automate.

## Ouvrir le projet

1. Clonez le dépôt ou téléchargez-le depuis GitHub.
2. Extrayez `Automatic Coffee Machine.rar`.
3. Ouvrez le projet extrait avec TIA Portal.
4. Vérifiez la compatibilité du projet et de la configuration matérielle avant tout transfert vers un automate.

Pour cloner le dépôt :

```bash
git clone https://github.com/ayoubnouayti/coffee-machine-tia-portal.git
```
